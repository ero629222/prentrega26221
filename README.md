# Pre-Entrega QA Automation: SauceDemo

Proyecto de automatización de pruebas UI con Selenium WebDriver y Pytest sobre [SauceDemo](https://www.saucedemo.com/).

## Requisitos y Tecnologías
- Python 3.10+
- Pytest
- Selenium WebDriver & WebDriver Manager
- pytest-html (Reportes)

## Instalación
```cmd
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
